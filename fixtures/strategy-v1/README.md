# Frozen strategy fixtures v1

These cases freeze policy-independent questions before `GameMemory v2`, arbitration or search
weights are fitted. Each case anchors to an immutable official-engine fixture but exposes only
facts classified as observed, officially derived or explicitly believed. Candidate labels separate
legality, feasibility and desirability; only desirability is a strategic judgment.

The suite is intentionally not an oracle for all of FCM. It is a compact adversarial gate covering
delayed activation, salary runway, demand donation, expiring opportunities, bait, restaurant
blocking, sequential inventory, milestone closure, hidden-state invariance and search cutoffs.
Changing a preferred label requires a new fixture version and evidence, not an evaluator-weight
change.
