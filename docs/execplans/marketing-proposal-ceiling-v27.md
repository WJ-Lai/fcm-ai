# Marketing proposal ceiling v27

## Objective

Separate the current 138/270 bounded marketing-effect coverage into production-budget loss,
single-action enumeration-selection loss, exhaustive legality/decoding loss and inherently
multi-marketing labels before changing the candidate generator.

## Method

1. Add an audit-only exhaustive enumerator over every advertised marketer, campaign, orientation,
   public house-effect set, good and legal finite duration. Collapse only coordinate aliases with
   identical public effects.
2. Prove with adversarial tests that intermediate durations and lower-ranked distinct house sets
   are retained while duplicate coordinate effects are collapsed.
3. Re-run the 50-game proposal-training corpus and freeze the loss decomposition.
4. Select one bounded production change using only training results, preregister its expected
   mechanism and validation gate, then evaluate once on games 51–100.

The exhaustive enumerator is diagnostic only. It must not become an unbounded online candidate
generator, and the independent validation slice must not influence feature, quota or threshold
selection.
